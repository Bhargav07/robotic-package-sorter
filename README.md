# robotic-package-sorter
Sort the packages Smarter Technology’s robotic automation factory, and your objective is to write a function for one of its robotic arms that will dispatch the packages to the correct stack according to their volume and mass using the below criteria 
A package is **bulky** if its volume (Width x Height x Length) is greater than or equal to 1,000,000 cm³ or when one of its dimensions is greater or equal to 150 cm. 
A package is **heavy** when its mass is greater or equal to 20 kg.
